# Changelog

All notable changes to the OSEL draft and to this repository are recorded
here. The operative license changes only when a versioned file under
`LICENSES/` changes.

## Unreleased

No change to the operative wording of OSEL 0.1 Sections 1 through 9.

### 0.2 discussion draft

- Added `LICENSES/OSEL-0.2-draft.txt`. The step is Evolution. The test is
  the Evolution Menu in Section 1.10. The draft does not amend 0.1.
- Added a reading map at `LICENSES/OSEL-0.2-draft.md` and a record form at
  `examples/EVOLUTION.md`.

### The idea, stated on its own

- Added `docs/evolution.md` and `docs/translations/zh-CN-idea.md`. The
  repository now leads with the lineage rule: a descendant may take on Menu
  duties, an ancestor stays put, and the line cannot be made thinner.

- Added the Markdown rendering `LICENSES/OSEL-0.1.md`. The plain-text file
  remains canonical.
- Moved the non-operative drafting notes out of `LICENSES/OSEL-0.1.txt` into
  `docs/rationale/drafting-notes.md`, and left a one-line editorial pointer
  after the application instructions.
- Added the annotated specification, OSD checklist, compatibility criteria,
  working compatibility list, comparison, open-question list, and proposed
  0.2 discussion text.
- Added examples for the source-file notice and for `LICENSE-REPLACEMENT.md`.
- Added `LICENSE`, `FAQ.md`, `CONTRIBUTING.md`, `GOVERNANCE.md`, `ROADMAP.md`,
  `CODE_OF_CONDUCT.md`, `AUTHORS.md`, and GitHub issue and pull request
  templates.
- Added an unofficial Simplified Chinese translation. English controls.
- Replaced the plain-text `README` with `README.md` and linked the documents
  the overview had named.
