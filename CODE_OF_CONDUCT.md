# Code of conduct

This project discusses license text. The discussion works only if people can
criticize a clause without attacking the person who proposed it.

## Expected

- Comment on the wording, the consequences for recipients and contributors,
  and the Open Source Definition.
- State when you are unsure. Distinguish a reading of the draft from a
  statement about what a court or OSI would do.
- Give other people time to reply to a normative proposal.
- Assume a correction of your citation is about the citation.

## Not accepted

- Harassment, slurs, or personal attacks.
- Publishing another person's private information.
- Presenting your own view as legal advice for a particular contributor or
  adopter.
- Claiming, in the project's name, that OSEL is OSI-approved, or filing the
  draft with a registry as if the project had decided to do so.
- Using the issue tracker to negotiate a private exception for one company
  or one product. The license is general or it is not OSEL.

## Reports

Report a conduct problem to the maintainers of the OpenReciprocal/open-source-evolution-license
repository through a private channel they have published, or, if none is
published, by opening a report only when it can be done without spreading
private information further. Maintainers will remove material that breaks
this file and may limit further participation.

Maintainer decisions under [GOVERNANCE.md](GOVERNANCE.md) are about the text.
This file is about how the discussion is conducted. A disagreement with a
technical decision is not, by itself, a conduct report.

## Scope

This file covers the repository, its issue tracker, and its pull requests.
It does not govern projects that merely apply OSEL to their own code.
