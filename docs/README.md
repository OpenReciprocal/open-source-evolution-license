# OSEL documentation

These pages explain the Open Source Evolution License. They are not the
license. Nothing here is legal advice or an OSI certification opinion.

## Read in this order

1. [The evolution idea](evolution.md). The sentence the project exists to
   carry, the Menu, and three scenes.
   [中文](translations/zh-CN-idea.md).
2. [OSEL 0.2 discussion draft](../LICENSES/OSEL-0.2-draft.md). The Menu
   written as license text. The plain text is
   [OSEL-0.2-draft.txt](../LICENSES/OSEL-0.2-draft.txt). It does not amend
   0.1.
3. [Annotated 0.1 specification](spec/OSEL-0.1.md) and the
   [0.1 license](../LICENSES/OSEL-0.1.txt). The published draft, with the
   gaps the later text is aimed at.
4. [Open questions](open-questions.md) and the
   [clause suggestions](rationale/proposed-0.2.md) that were assembled into
   the discussion draft.
5. [OSD checklist](compliance/osd-checklist.md),
   [0.1 compatibility criteria](compatibility/criteria.md), the
   [working list](compatibility/known-compatible-licenses.md), and the
   [comparison](comparison/comparison-with-other-licenses.md). Reference
   for the 0.1 text.
