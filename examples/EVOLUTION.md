# Evolution record

Form for the record required by Section 5 of the Open Source Evolution
License, Version 0.2 (discussion draft). It is not a completed step, and it
is not a finding that any named license is an Evolution Target.

Delete this banner when you use the form. A record that still contains
angle brackets does not satisfy the draft. Do not use this file to evolve
software that was released under Version 0.1. Version 0.1 requires
`LICENSE-REPLACEMENT.md` and uses a different test.

Version 0.2 does not pre-approve GPL-3.0, AGPL-3.0, Apache-2.0, MPL-2.0,
EUPL-1.2, or any other license. Map the target onto the Evolution Menu
yourself. If you cannot fill the Menu section, do not ship the record.
